# `src-tauri/` — surface pointer

이 디렉토리를 만지기 전 `memory/index/by-surface.md` 의 `src-tauri/**` 절과
거기가 가리키는 convention 방(`memory/engineering/conventions/backend/memory.md`,
`memory/engineering/conventions/rust/memory.md` 등)을 읽어라. 인덱스는 찾아가야
오고, 마크다운 링크는 자동으로 안 따라간다.

규칙 본문은 `memory/` 가 SOT다 — **여기 본문을 적지 마라.** 적는 순간 drift 한다.
