# H7 진행 기준

H7 운영/보안/신뢰성은 **자동 gate 와 support claim 을 실제 설정에 맞추는 정합성
gate**다. H7 closure 는 a11y/perf/link-check/platform smoke 가 routine blocking
gate 로 새로 승격됐다는 뜻이 아니다. 새 gate 는 active feature lane 을 실제로 막고,
owner 와 runtime cost 가 명확하며, failure triage 경로가 있을 때만 승격한다.

| Gate | Current owner | H7 boundary |
|---|---|---|
| PR/main CI gates | `.github/workflows/ci.yml`, `.github/workflows/e2e-smoke.yml` | The merge-blocking set is listed once, in `memory/runbook/pr-merge-gates/memory.md`; this row deliberately keeps no copy, because the copy it used to keep went stale. Three of the eight required contexts verify nothing. Full a11y, perf, link-check, and cross-platform runtime smoke are not routine blocking gates. |
| Local hook gates | `memory/workflow/git-policy/memory.md` | There are none. No git hook runs locally, so bypass flags, unsigned commits, pull/reset recovery hazards, and force-push are forbidden by policy alone, with nothing enforcing it. |
| Fixture/test topology | `memory/engineering/conventions/testing-scenarios/fixtures/memory.md`, `docs/contributor-guide/fixture-test-topology-inventory.md`, `docs/contributor-guide/testing-and-quality.md` | Refactor 04 fixture/test topology closes only when DBMS-first fixture roots, test placement, support-claim boundaries, and smoke-routing tiers stay aligned. Fixture existence is contract evidence only until a consuming test plus product-doc review plus smoke-routing decision promotes it. Live GitHub audit on 2026-06-12 shows parent #575 and milestone #40 closed after #755 and the remaining Refactor 04 children landed. |
| Runtime E2E smoke | `wdio.smoke.conf.ts`, `e2e/smoke/**` | Nothing runs these specs. `Runtime Happy Path` reports a required context with no runtime coverage behind it, so the specs are hand-run evidence only (README 「E2E Smoke」). Any support claim that cites remote smoke needs a runner first. |
| Security/destructive policy | `docs/product/query-language-support.md`, `docs/product/known-limitations.md` | Current destructive protections are source-specific preview/confirm/Safe Mode/typed confirmation paths. There is no universal admin/security dashboard, role/user/permission UI, credential rotation UI, or global audit-log claim. Security-impacting decisions follow a threat-model review before option selection. |
| Credential/privacy boundary | `memory/engineering/architecture/state-management/memory.md`, `docs/product/README.md`, `docs/product/known-limitations.md` | Table View remains local-first. Connection export omits passwords, imported connections require password re-entry, and local file analytics public payloads redact absolute paths. 2026-07-25 오너 grill 실측: export 비밀번호 부재와 import 재입력 강제는 `src-tauri/src/commands/connection/io.rs` 단위 테스트가 덮고, 로컬 파일 절대경로 redaction 은 `src-tauri/src/db/duckdb/file_analytics.rs` 와 `e2e/smoke/duckdb-file-analytics.spec.ts` 가 덮는다. 남은 공백은 실제 Rust backend 를 관통하는 export → 파일 → import 왕복 증거이고 (`e2e/smoke/` 에 connection import/export spec 0건), #1815 가 소유한다. Path C 디스크 fallback 을 거친 file-key 를 keyring 복귀 시 재키잉하는 작업은 #1814 다. |
| A11y/perf/link-check/platform smoke | `docs/contributor-guide/testing-and-quality.md`, `.github/workflows/ci.yml` | Existing component/unit checks and advisory theme contrast do not equal routine screen-reader, FPS/latency, link-check, macOS runtime, or Windows runtime gates. Promote only when a lane needs a concrete owner and budget. |

H7 umbrella closure means ops/security/reliability documentation, smoke matrices,
and known limitations no longer overstate the current automated gate surface. It
does not mean all H7 implementation gaps have shipped.
