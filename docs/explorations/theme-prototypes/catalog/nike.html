-- 최근 30일 고객별 매출
SELECT c.id, c.name, SUM(o.total_amount) AS revenue
FROM orders o
JOIN customers c ON c.id = o.customer_id
WHERE o.created_at >= NOW() - INTERVAL '30 days'
AND o.status <> 'cancelled'
GROUP BY c.id, c.name
HAVING SUM(o.total_amount) > 1000
ORDER BY revenue DESC
LIMIT 50;

디자인 노트

  • 강조: primary 흑/백(#000000 light / #ffffff dark)만 쓰고 색으로 강조하지 않는다 — "athletic bold" 는 색이 아니라 굵기·각·대비로 낸다.
  • vibe 튜닝 ①: Google Fonts Archivo Black 을 h1/섹션 헤딩에만 적용 — 본문·데이터 그리드는 그대로 시스템 산세리프를 유지해 밀도를 지켰다.
  • vibe 튜닝 ②: 테마 id 배지(mintlify 자리의 nike)에 clip-path 로 각진 절단을 줘 라벨/태그 하나에서도 각진 실루엣이 보이게 했다.
  • vibe 튜닝 ③: --tv-radius 를 이 테마만 0.5rem → 2px 로 낮춰 버튼·카드·인풋이 거의 직각으로 떨어지게 했다.
  • dark-first: 이 테마는 data-mode="dark" 로 시작한다 — 배경 #111111, primary 가 흰색으로 뒤집혀 순흑 배경 위 순백 CTA 라는 극단적 대비를 기본값으로 삼았다.
