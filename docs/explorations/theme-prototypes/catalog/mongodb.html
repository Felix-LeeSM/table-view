G — Design notes
  • 인스펙터는 표 형태 대신 도큐먼트(Document) 뷰를 기본으로 열어 JSON 트리를 전면에 배치했다 — MongoDB가 다루는 단위는 컬럼이 아니라 도큐먼트라서, 세그먼트 컨트롤도 Document 쪽을 활성 상태로 둔다.
  • primary는 light에서 #00684a(포레스트 그린), dark에서 #00ed64(네온 그린)로 크게 벌어진다 — 실제 MongoDB Compass가 다크 모드에서 채도 높은 그린을 쓰는 것과 같은 전환을 그대로 반영했다.
  • 얼룩말 줄무늬는 넣지 않았다 — 헤어라인 보더만으로 밀도를 유지하는 쪽이 데이터 그리드 성격에 더 맞는다.
  • light/dark 모두 src/themes.css 실값 그대로이며 radius·폰트 등 추가 보정은 없다.
