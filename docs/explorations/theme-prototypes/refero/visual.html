-- 최근 30일 고객별 매출
SELECT c.id, c.name, SUM(o.total_amount) AS revenue
FROM orders o
JOIN customers c ON c.id = o.customer_id
WHERE o.created_at >= NOW() - INTERVAL '30 days'
AND o.status <> 'cancelled'
GROUP BY c.id, c.name
HAVING SUM(o.total_amount) > 1000
ORDER BY revenue DESC
LIMIT 50;

design notes

디자인 노트

  • 두 축 타이포. Fraunces 세리프 96px/300 은 헤딩·디스플레이 전용이고, 앱 셸 안쪽은 탭·툴바·그리드·에디터·인스펙터·상태바까지 전부 IBM Plex Mono 로 통일했다. DB 툴의 조밀함은 등폭에서 나온다.
  • 노란 형광펜, 4번만. Highlighter Yellow(#fff347)는 히어로 태그라인의 강조 구절, 데이터 그리드의 편집 중 셀 마커, 팔레트 스와치, SQL 에디터 Run 버튼의 ⌘↵ 칩까지 화면당 정확히 4번 썼다 — 텍스트 색·큰 배경·채운 버튼에는 한 번도 쓰지 않았다.
  • 그림자 없음. box-shadow 는 페이지 전체에 하나도 없다. 위계는 1px hairline 두 단(Ash 기본, Olive Char/Sage 구조 경계)과 80px 섹션 간격으로만 세웠다.
  • 뺀 것. 카드/버튼 드롭섀도, 그라디언트, 차가운 회색, 파란·보라 계열 강조색, 16px 이하 세리프 본문 — 전부 의도적으로 뺐다.
  • 다크 모드 = 밤 인쇄판. 반전이 아니라 Carbon(#2c2c26)을 배경으로 올린 해석이다 — 같은 올리브-세이지 색군, 같은 평면성, 같은 노랑 절제(≤4회)를 그대로 지켰다. Sage/Moss 는 라이트에서는 대비 미달이라 쓰지 않았던 색인데, 다크에서는 배경이 어두워지며 그대로 muted-foreground/status-idle 로 자연스럽게 재사용됐다. primary 만 Carbon → Vellum 으로 뒤집어 어두운 배경 위에서 버튼이 읽히게 했다.
