-- 최근 30일 고객별 매출
SELECT c.id, c.name, SUM(o.total_amount) AS revenue
FROM orders o
  JOIN customers c ON c.id = o.customer_id
WHERE o.created_at >= NOW() - INTERVAL '30 days'
  AND o.status <> 'cancelled'
GROUP BY c.id, c.name
HAVING SUM(o.total_amount) > 1000
ORDER BY revenue DESC
LIMIT 50;

디자인 결정

  • 기존 linear 테마와의 차이. src/themes.css 의 [data-theme="linear"] 는 primary #5e6ad2 보라 유채색 강조 + 범용 shadcn 슬레이트 회색조를 쓴다. 이 console 은 그 자리를 대체하는 게 아니라 별개의 정밀 판본이다 — primary 를 포함해 유채색 브랜드 강조가 전혀 없고, 이름 붙은 고유 무채색 14단 계단으로 표면을 층층이 쌓는다.
  • 채움 없는 주 액션. Run/Commit 같은 primary 버튼은 dark 에서 Snow, light 에서 Onyx Canvas 잉크의 아웃라인 pill 로 세운다. 강조는 채도가 아니라 배경 대비가 가장 큰 테두리색과 weight 590 텍스트가 맡는다. hover 는 10% color-mix 워시만 얹고, 정지 상태의 실루엣은 항상 테두리뿐이다.
  • 상태 4종. connected/connecting/error 3종은 SPEC 4절이 이미 테마 무관 고정값(success/warning/destructive)으로 박아 둔 색이라 재사용해도 "이 테마의 브랜드 유채색"이 아니다 — src/themes.css 의 기존 72개 테마 전부(순수 모노크롬이라는 vercel 포함) 상태 점만은 테마와 무관하게 동일한 색을 쓴다. idle 만 이 테마 고유의 무채색 (Steel/Fog Text)으로 남겨 "보고할 것 없음"을 채도 0으로 표현했다.
  • 구문 강조 12종. weight·구조가 1차 신호다 — punct/comment 는 무채색으로 가장 낮은 대비까지 가라앉히고 keyword 는 590 굵기로 세운다. 나머지 8개 콘텐츠 토큰만 채도 15~35% 대의 옅은 색 하나씩 배정해 스캔 가능성을 살렸다. error 만 고정 destructive 빨강을 그대로 재사용한다.
  • light 모드. 반전이 아니라 같은 14단 계단을 뒤집어 다시 쌓은 해석("낮의 천문대") — 배경은 Snow(dark 의 foreground 재사용), 잉크는 Onyx Canvas(dark 의 background 재사용), border/ring/muted-foreground 는 각각 Chalk/Mist/Steel Text 재사용. card/popover 만 계단에 더 밝은 단이 없어 순백을 새로 썼고, hover/pressed 는 반대로 회색 쪽으로 내려간다. 같은 hairline 문법·같은 아웃라인 pill·같은 weight 510/590 은 그대로.
