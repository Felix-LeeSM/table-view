디자인 노트

  • 얇은 회색 대신 진한 잉크선. border/input 은 Slate 1~1.5px 를 그대로 써서 그림자보다 선이 구조를 만드는 관찰 노트 질감을 우선했다. 그리드 내부 행 구분선만 --tv-border 를 옅게 섞은 hairline 으로 낮췄다.
  • 데이터 시각화 6색은 SQL 구문 강조에만 배분. Olive/Plum/Saffron/Iris/Deep Forest/Deep Teal — 금지 규칙이 이 6색을 차트·일러스트 전용으로 못박아, 상태 점·배지 등 일반 UI 에는 Meadow/Buttercream 같은 카드용 파스텔과 고정 success/warning/destructive 만 썼다.
  • 밀도 우선. 큰 radius 시스템이어도 그리드 행은 8px 상하 패딩 · 13px 텍스트로 눌러 30px 안팎을 지켰다. 얼룩말 줄무늬는 원장부 가로줄 질감과 맞아 옅게(--tv-muted 45%) 넣었다.
  • 다크 모드 — "밤의 숲 바닥". 라이트의 Forest Ink(잉크)↔Parchment(종이) 역할을 맞바꿔 배경/전경/primary 를 반전했다. card·popover·accent 3단 표면은 Forest Ink→Slate 보간으로 새로 뽑아 밝기 순서(0.011→0.026)를 유지했고, 파스텔·데이터 시각화 6색은 흰색 쪽으로 55% 섞어 다크 카드 위에서도 6:1 이상 대비를 냈다. 그림자는 같은 5겹 forest-ink 처방을 쓰되 alpha 만 올려 "같은 그림자 문법"을 지켰다.
  • 배지는 solid fill 대신 옅은 wash. success/warning/destructive 를 12~14% 배경 + 같은 색 텍스트로 써서, 채도 있는 사각 블록이 파스텔·양피지 세계관과 부딪히지 않게 뺐다.
