1-- 최근 30일 고객별 매출
2SELECT c.id, c.name, SUM(o.total_amount) AS revenue
3FROM orders o
4JOIN customers c ON c.id = o.customer_id
5WHERE o.created_at >= NOW() - INTERVAL '30 days'
6AND o.status <> 'cancelled'
7GROUP BY c.id, c.name
8HAVING SUM(o.total_amount) > 1000
9ORDER BY revenue DESC
10LIMIT 50;

G · 디자인 노트

  1. 페이지 캔버스(하늘)는 앱 셸 바깥 몫이다 — light 는 Signal Yellow, dark 는 Globe Azure. 앱 셸 내부(--tv-background 이하)는 항상 White/Ink 두 무채색의 명도 반전만으로 그렸다.
  2. radius 1440px 은 원형 전용(상태 점·탭 인디케이터·토글 손잡이·스위치 손잡이)에만 썼다. 시스템이 명시한 "카드 0·pill 0·버튼 0" 을 그대로 지켜 사각 컨테이너·버튼·뱃지·인풋은 전부 0px.
  3. Roof Coral 은 --tv-* 토큰 어디에도 안 썼다(destructive·syntax-error 포함, 둘 다 이미 고정된 시스템 red 를 재사용) — UI 크롬 절대 금지를 문자 그대로 지켰다.
  4. 구문 강조 12종은 Azure 명도 계단(keyword→type→builtin/function→property) + Charcoal 그레이 축(operator/punct/comment) + 이 파일에 이미 고정으로 존재하는 시스템 토큰 재사용(number/error/atom)으로 풀었다. 새 hue 없이 12개 전부 카드 배경 기준 AA 4.5:1 이상.
  5. dark = "해질녘/밤의 디오라마": 하늘이 Azure 로 넘어가고 낮의 primary 였던 Yellow 는 실내 강조(창문·달빛)로 자리를 바꾼다. 같은 다섯 색, 같은 평면, 같은 원형 초점. 알려진 한계: primary/destructive 솔리드 버튼 라벨은 light 에서 각각 3.83:1 / 3.76:1 로 AA 미달 — 5색 고정 hex·무굵기 제약 안의 한계이며, 앱 셸 안 본문·데이터 텍스트는 전부 4.5:1 이상을 확보했다.
