-- 최근 30일 고객별 매출
SELECT c.id, c.name, SUM(o.total_amount) AS revenue
FROM orders o
JOIN customers c ON c.id = o.customer_id
WHERE o.created_at >= NOW() - INTERVAL '30 days'
AND o.status <> 'cancelled'
GROUP BY c.id, c.name
HAVING SUM(o.total_amount) > 1000
ORDER BY revenue DESC
LIMIT 50;

Notes

디자인 결정

  • 기능색은 Void Violet 하나뿐이다. 상태 점(connected/connecting/error) 세 개만 예외로 브리프가 "데모용"이라 명시한 Deep Teal·Signal Blue·Ember Glow 를 썼다 — 버튼·배지·링크 같은 브랜드 크롬에는 쓰지 않았다.
  • SQL 구문 강조는 새 색을 만들지 않고 src/themes.css 가 이미 쓰는 AA 검증된 cool_dark/cool_light 프리셋을 그대로 재사용했다 (keyword 가 이미 바이올렛 계열이라 톤이 맞는다). light 모드 builtin/function 만 0891b2→0a7a95 로 살짝 깊게 조정 (대비 3.14:1→4.23:1, 배경이 순백이 아니라 살짝 어두운 안개색이라).
  • 라디우스는 컴포넌트별 스펙을 요약줄보다 우선했다: solid 버튼(Primary/Destructive)·배지·인풋 6px, ghost/secondary pill·토글 999px, 카드·모달 16px, 아이콘 컨테이너(엔진 배지) 9999px — 한 컴포넌트 안에서는 섞지 않았다.
  • 얼룩말 줄무늬는 뺐다. 유리·여백 위주 무드에 줄무늬가 어울리지 않는다고 판단.
  • light 모드는 반전이 아니라 해석: 배경을 흰색이 아니라 옅은 안개빛 하늘색으로 바꾸고, 잉크 극성을 뒤집었다(어두운 유리 위 밝은 텍스트 → 밝은 유리 위 어두운 텍스트). hairline·글래스 알파값은 dark 와 동일 문법을 유지, 워드마크 Skywash 그라디언트만 밝은 하늘색 → 짙은 네이비 그라디언트로 다시 튜닝했다(원래 그라디언트는 밝은 배경에서 거의 안 보인다). 상태 점 3종은 AA 3:1 을 넘기려고 밝은 배경용으로 더 짙게 조정했다(계산: 위 Live tokens 스와치 참고).
