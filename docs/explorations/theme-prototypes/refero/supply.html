DESIGN NOTES

  • 상태 4종 — 점(connected, 솔리드)·삼각형(connecting, pulse 애니메이션)·빗금사각(error)·빈사각(idle) 4어휘로 톤 계단과 결합. 배지의 성공/경고/오류/중립도 같은 어휘를 재사용했다 — --tv-success/--tv-warning(그린/오렌지)은 토큰엔 남기되 화면엔 안 썼다: 이 테마의 "유채색 금지"는 예외가 명시된 gradient 1건 외엔 카드/전역 상관없이 전부 적용된다고 읽었다.
  • 구문 강조 12종 — light 는 5단 톤 사다리(#101010→#c8c8c8, keyword/function 2·builtin/type/number 3·property/atom/string 3·operator/comment 2·punct 1)에 italic·underline·tracking 을 얹어 9종은 AA(4.5:1) 이상, operator·comment·punct 3종은 코드 에디터 관례대로 의도적 저대비. dark 는 4단으로 접힌다 — #101010 을 dark 배경(#101010) 위 텍스트로 두면 대비 1:1(실측)로 사라져서, light 의 4·5단을 하나(#555555, 2.55:1)로 합쳤다.
  • destructive / status-error 는 유채색을 안 썼다 — 금지 목록에 이 둘만의 예외가 없고, 이 페이지의 핵심 실험(무채색으로 상태를 구분하기)을 가장 위험한 지점에서 스스로 깨는 걸 피했다. 대신 Charcoal 솔리드 필 + 흑백 이색 빗금 글리프를 썼다 — 빗금은 라이트/다크 어느 벽 색과도 자기대비가 항상 최대라서, 톤 하나로는 못 푸는 "다크에서 검정이 검정 위에서 사라지는" 문제를 우회한다.
  • dark 모드는 벽을 #101010 으로 뒤집은 해석이다 — 8색 팔레트 밖으로 안 나가고, light 에서 배경 쪽 끝에 있던 톤들(border-subtle → border-soft)을 dark 에서 반대쪽 끝 톤(muted-hard → muted)이 같은 랭크로 이어받는다. popover 만 두 모드에서 값이 같다(#222222) — "모달만 어두운 판(plinth)"이라는 팔레트 표의 역할 설명을 문자 그대로 따른 결과다.
  • AA 대비 예외 — 팔레트 표는 Muted Soft(#999999)를 "섹션 헤딩"에도 쓰라고 하지만 흰 배경 위 실측 대비가 2.85:1로 3:1 미달이라, 실제 읽는 텍스트에는 Muted(#555555, 7.45:1)를 쓰고 #999999는 아이콘·hover 테두리(비텍스트, 기준 예외)로만 한정했다. dark 배경에서는 같은 #999999가 6.68:1이라 muted-foreground 로 정상 승격된다.
  • 뺀 것 — 얼룩말 줄무늬(hairline 로 이미 행이 분리돼 있어 패턴 과다 방지), box/drop shadow 전부, 산세리프 전부. 인스펙터 JSON 트리의 key/leaf/delete 색만은 SPEC 이 "테마 무변, 그대로 복사"로 못박은 전역 아이덴티티라 이 테마의 무채색 규칙 밖에 둔다.
