# ci-uncalled-tests.txt — CI 가 안 부르는 src-tauri 통합 테스트 binary 의 allowlist (issue #2113).
#
# `scripts/check-ci-test-calls.sh` 가 읽는다. 그 스크립트가 미호출로 판정한 통합
# 테스트 target 은 전부 여기 사유와 함께 있어야 하고, 없으면 CI 의
# `PR Body Contract` 가 red 다. 무엇을 target 으로 치고 무엇을 호출로 치는지는 그
# 스크립트 헤더가 SOT 다 — 같은 규칙을 여기 다시 적으면 게이트가 바뀌는 날 이
# 사본만 낡는다.
#
# 형식: 한 줄에 `<테스트 이름><공백><사유>`. `#` 로 시작하는 줄과 빈 줄은 무시하고,
# 사유가 비면 위반이다. 정렬은 관례일 뿐 가드는 순서를 안 본다.
#
# ## 줄을 지워야 하는 때
#
# 이 파일은 줄어들기만 한다. 테스트를 workflow 의 `--test` 로 부르기 시작했거나
# 파일을 지웠으면 여기 줄도 같은 PR 에서 지운다 — 둘 다 가드가 위반으로 잡는다.
#
# ## 사유 `measured-2559` 는 시딩분을 실행해서 얻은 판정이다
#
# 이 사유가 붙은 줄은 이 게이트가 생기기 전부터 미호출이던 시딩분이고, 처음 사유는
# `seed-2113` 이었다. #2559 가 `fd557c1104e6` 트리에서 줄마다 아래 명령을 로컬
# (macOS aarch64, Docker 기동)로 돌렸고, 첫 실행의 결과를 판정으로 삼아 사유를
# `measured-2559 <판정> <근거 요약>` 으로 바꿨다.
#
#   cargo test --manifest-path src-tauri/Cargo.toml --test <이름> -- --nocapture
#
#   fail = rc 가 0 이 아니다
#   skip = rc 는 0 이지만 통과한 테스트가 없거나 출력에 `SKIP:` 줄이 있다
#   pass = rc 가 0 이고 통과한 테스트가 1 개 이상이며 `SKIP:` 줄이 없다
#
# `PGHOST` · `MONGO_HOST` 같은 DB endpoint 환경 변수 없이 돌렸으므로, 서버 DB 에 붙는
# target 은 테스트 helper 가 직접 띄운 testcontainers 컨테이너를 썼다 (근거 요약 끝 괄호의
# 이미지). 판정은 그 트리에서 잰 값이지 CI 결과가 아니다.
# #2705 가 pass 를 CI 에 붙이고 그 줄을 지웠으므로, 남은 `measured-2559` 줄은 fail
# 이고 target 마다 따로 여는 이슈가 고친다. 남은 이름은 아래 명령으로 뽑는다:
#
#   awk '$1 !~ /^#/ && $2 == "measured-2559" {print $1, $3}' ci-uncalled-tests.txt
#
# ## 사유 `excluded-2559` 는 측정분 가운데 CI 에 붙이지 않기로 한 줄이다
#
# #2705 가 pass · skip 을 CI 에 붙일 때, 붙여도 아무 테스트가 돌지 않는 target 은
# 붙이지 않고 사유를 `excluded-2559 <사유>` 로 바꿨다. `all-ignored` 는 그 target 의
# 테스트가 모두 `#[ignore]` 라는 뜻이다.
#
# 새로 추가하는 줄은 측정분이 아니므로 진짜 사유를 적어라.
#
# 이 파일의 이름 집합은 게이트가 세는 미호출 집합과 정확히 같아야 한다. 지금 값은
# 게이트를 돌리면 집계 줄에 나온다 — 통과하면 `ok:` 줄, 위반이 있으면 `집계:` 줄:
#
#   bash scripts/check-ci-test-calls.sh

cancel_pg                                     measured-2559 fail 2 passed; 1 failed; 0 ignored — pg_execute_query_tracked_pid_enables_native_cancel 이 :156 의 10초 join 예산을 넘겼다, 다시 돌린 5회 중 4회 재현 (testcontainers postgres:11-alpine)
migration_apply                               measured-2559 fail 6 passed; 2 failed; 0 ignored — :64 · :245 가 테이블 11개를 단언하는데 migration 0006_ssh_host_key_pins.sql 이 12번째 테이블을 더했다
oracle_smoke_boundary_probe                   excluded-2559 all-ignored — 7개 모두 #[ignore] (Oracle 컨테이너와 e2e/fixtures/seed.oracle.sql 필요) 라서 --test 로 불러도 아무 테스트도 돌지 않는다
